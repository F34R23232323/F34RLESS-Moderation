# Review And Appeals

Pending Review Quarantine is reversible and is not a finding of guilt. It uses a persistent permissionless role rather than a Discord timeout represented as permanent. Evidence, audit entry, rule, app identifiers, role snapshot, reviewer, reason, and each state transition are append-only.

Release removes only the anti-nuke quarantine role. Dangerous permissions are never restored automatically. Staff messages must use `allowedMentions` with `parse: []` and at most the configured reviewer role.
